# Thuthu Hlatshwayo — Professional Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `styles.css` — layout, typography, colour and responsive styling
- `script.js` — mobile navigation behaviour
- `assets/` — reserved for images and downloadable documents

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload all files and folders in this package to the root of the repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment to complete and open the published URL.

## Custom domain
After registering `thuthuhlatshwayo.com`, configure it in **Settings → Pages → Custom domain** and add the DNS records GitHub Pages specifies. Enable HTTPS once DNS verification is complete.

## Notes
- The site currently links the contact action to LinkedIn.
- The page uses Google Fonts; system fallbacks are included.
- No framework, build step or package installation is required.
- Review all public-facing claims and links before publishing.
